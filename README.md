# 생활·금융 계산기 (smart-calc)

복리·적립, 주식·ETF 월배당, 부동산·대출, 복비, 청약 가점, 연봉·세금, 연차·퇴직금, 실업급여, 출산·육아휴직을 한 사이트에서 계산하는 정적 웹사이트입니다.
빌드 과정이 없고, GitHub Pages에 그대로 올라가는 구조입니다.

- 배포 주소: https://handobin9782-lang.github.io/smart-calc/
- 메뉴: 모든 페이지 상단의 `☰ 전체 계산기`(카테고리 카드형)와 `index.html` 상단 허브 카드에서 9종 계산기로 이동합니다.

## 카테고리

- **① 금융·투자** — 복리·적립식, 주식·ETF 월배당
- **② 부동산·주거** — 부동산·대출(주담대), 부동산 복비, 청약 가점
- **③ 직장·생활** — 연봉 실수령, 연차·퇴직금, 실업급여, 출산·육아휴직

## 기능

- **복리 계산기**: 초기 투자금 · 매월 적립금 · 연 수익률 · 기간으로 최종 자산, 순수 복리 수익, 원금 대비 수익률, 만기 시 연 4% 월 현금, 물가 2% 반영 실질 가치, 복리 수익이 원금을 넘어서는 시점을 계산합니다. 결과 카드의 `이 자산으로 SCHD 등 ETF 월배당 계산하기` 버튼으로 계산한 자산을 월배당 계산기로 넘깁니다.
- **프리셋**: 주식·ETF 적립(500만 + 월 50만·15년), 공제회·연금(월 30만·20년), 코인 적립식(100만 + 월 20만·10년), 목돈 배당 재투자(1억·10년).
- **월배당 계산기**: 투자금과 연 배당률(SCHD 3.5%·리얼티인컴 5.5%·커버드콜 10% 프리셋), 계좌(일반 15.4%·ISA·연금저축 0%·연금 수령 5.5%)을 골라 세후 월 배당금, 세후 연 배당금, 세전 배당금, 예상 세금을 계산합니다. 배당 성장률에 따른 30년 시뮬레이션과 목표 월 배당 역산도 제공합니다.
- **주담대 계산기**: 상환방식 3종과 거치기간을 반영해 월 상환액, 총 이자, 총 상환액, 연도별 원금·이자·잔액을 계산합니다.
- **복비 계산기**: 매매·전세·월세를 고르고 거래금액(월세는 보증금 + 월세×100, 5,000만 원 미만이면 ×70)을 넣으면 구간별 법정 상한요율·한도액으로 중개보수를 계산하고, 협의 요율과 부가세 10% 별도 여부를 반영합니다.
- **청약 가점 계산기**: 무주택기간(32점)·부양가족수(35점)·청약통장 가입기간(17점)을 84점 만점으로 실시간 계산하고 항목별 점수와 막대를 보여줍니다. 배우자 통장 50%(최대 3점) 가산, 만 30세 미만 미혼 0점 처리.
- **연봉 계산기**: 국민연금·건강보험·장기요양·고용보험과 소득세·지방소득세를 항목별로 보여줍니다.
- **연차·퇴직금 계산기**: 재직일수·근속연수, 법정 연차, 퇴직금(평균임금×30×재직일수/365), 퇴직소득세와 실수령 퇴직금을 계산합니다.
- **실업급여 계산기**: 급여기초임금일액 60%에 상·하한을 적용한 1일 구직급여액과 소정급여일수, 총 수령액을 계산합니다.
- **출산·육아휴직 계산기**: 통상임금과 휴직 개월(1~18)로 월별 육아휴직 급여를 계산합니다. 1~3개월 100%·250만, 4~6개월 100%·200만, 7개월 이후 80%·160만, 하한 70만 원. 6+6 부모육아휴직제(250·250·300·350·400·450만)를 켜고 끌 수 있고, 출산전후휴가 90·100·120일과 배우자 출산휴가 20일 급여도 계산합니다.
- **조건 공유**: `?init=500&monthly=50&rate=10&years=15`(복리), `dividend.html?amount=10000&yield=3.5&tax=0.154&growth=3&goal=50`(월배당), `brokerage.html?type=sale&price=30000&rate=0.4&vat=1`(복비), `parental.html?wage=300&months=12&sixsix=1`(육아휴직) 형태로 조건을 URL에 담을 수 있습니다.

## 계산 방식

- 월 이율은 연 수익률을 12로 나누지 않고 `(1+r)^(1/12)-1`로 환산합니다. 12개월을 모으면 연 수익률과 정확히 일치합니다.
- 매월 적립금은 **월말 납입**으로 계산합니다.
- 월배당은 배당률과 세율이 매년 유지된다는 가정으로 계산하고, 일반 계좌 15.4%(소득세 14%+지방소득세 1.4%)·연금 수령 5.5%를 적용합니다. 금융소득종합과세(연 2,000만 원 초과)와 ISA 비과세 한도는 별도 안내로만 다룹니다.
- 중개보수는 「공인중개사법 시행규칙」 별표 1(2021. 10. 19. 신설)의 주택 상한요율·한도액을 적용합니다. 매매 0.6/0.5/0.4/0.5/0.6/0.7%, 임대차 0.5/0.4/0.3/0.4/0.5/0.6% 구간이며, 5,000만 원 미만 25만·20만 원, 매매 2억 원 미만 80만 원, 임대차 1억 원 미만 30만 원의 한도가 있습니다.
- 청약 가점은 「주택공급에 관한 규칙」 별표 1 배점표를 그대로 적용합니다. 무주택기간은 만 30세(30세 이전 혼인 시 혼인신고일)부터, 통장은 최초 가입일부터 셉니다.
- 육아휴직 급여는 2025년 1월 1일 이후 개시 기준(고용보험법 시행령 제95조)과 6+6 특례(제95조의2) 상한표를 적용하고, 출산전후휴가·배우자 출산휴가 급여는 2026년 고용노동부 고시 상한액(90일 660만·미숙아 100일 733만·다태아 120일 880만·배우자 20일 168만 4,210원)을 씁니다.
- 2026년 기준 요율: 국민연금 9.5%(근로자 4.75%, 기준소득월액 상한 659만·하한 41만), 건강보험 7.19%(3.595%), 장기요양 0.9448%(건강보험료의 13.14%), 고용보험 1.8%(0.9%).
- 실업급여는 2026년 1월 1일 이후 이직자 기준 1일 상한 68,100원(기초일액 113,500원×60%), 하한 66,048원(최저임금 10,320원×8시간×80%)입니다.
- 퇴직소득세는 근속연수공제 → 환산급여 → 환산급여공제 → 기본세율 → 근속연수 안분 순서로 계산합니다.
- 모든 결과는 세전·수수료 미반영 기준이며, 매년 같은 조건이 유지된다는 가정 위의 참고값입니다.
