# 복리·적립식 자산 계산기 (smart-calc)

적립식 복리 계산기 + 일반 계산기를 한 장의 정적 HTML로 구현한 무료 웹사이트입니다.
빌드 과정이 없고, GitHub Pages에 그대로 올라가는 구조입니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 계산기 본체 + 사용법·복리 원리·계산 예시·FAQ (SEO 메타, Open Graph, JSON-LD 포함) |
| `privacy.html` | 개인정보처리방침 및 광고(애드센스) 고지 |
| `robots.txt` | 검색 로봇 허용 및 사이트맵 위치 안내 |
| `sitemap.xml` | 색인용 사이트맵 |
| `og.png` | SNS 공유 미리보기 이미지 (1200×630) |

## 기능

- **복리 계산기**: 초기 투자금 · 매월 적립금 · 연 수익률 · 기간을 입력하면 최종 자산, 순수 복리 수익, 원금 대비 수익률, 만기 시 연 4% 월 현금, 물가 2% 반영 실질 가치, 복리 수익이 원금을 넘어서는 시점을 계산합니다.
- **프리셋**: 주식·ETF 적립(월 50만·15년), 공제회·연금(월 30만·20년), 코인 적립식(월 20만·10년), 목돈 배당 재투자(1억·10년).
- **연도별 성장 그래프와 표**: 원금과 복리 수익을 색으로 구분해 보여줍니다.
- **일반 계산기**: 사칙연산, 퍼센트.
- **조건 공유**: `?init=500&monthly=50&rate=10&years=15` 형태로 조건을 URL에 담을 수 있습니다.

## 계산 방식

- 월 이율은 연 수익률을 12로 나누지 않고 `(1+r)^(1/12)-1`로 환산합니다. 12개월을 모으면 연 수익률과 정확히 일치합니다.
- 매월 적립금은 **월말 납입**으로 계산합니다.
- 모든 결과는 세전·수수료 미반영 기준이며, 매년 같은 수익률이 유지된다는 가정 위의 참고값입니다.

## 배포

GitHub Pages의 `main` 브랜치 루트를 그대로 사용합니다. 별도 빌드·의존성이 없어 파일을 고치고 커밋하는 즉시 반영됩니다.
